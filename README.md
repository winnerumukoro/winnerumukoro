## Featured Projects

### [DocuMind AI](https://github.com/winnerumukoro/documind-ai)
A RAG (Retrieval-Augmented Generation) chatbot that lets you upload PDF or TXT documents and have real conversations with them. Ask questions, get grounded answers with source citations — powered by Google Gemini, FAISS, and LangChain.

`Python` `LangChain` `FAISS` `Google Gemini` `Streamlit`

---

### [Voice Task Assistant](https://github.com/winnerumukoro/voice-task-assistant)
A mobile app built with React Native + Expo where you speak your tasks and it handles the rest. Currently supports voice capture and speech-to-text transcription, with AI-powered task extraction and Google Calendar integration planned next.

`TypeScript` `React Native` `Expo` `Speech Recognition`

---

### [YouTube Summariser](https://github.com/winnerumukoro/youtube-summarizer)
Paste a YouTube link, get back a clean summary. Extracts the video transcript and uses AI to distil long-form content into the key points - useful when you don't have 45 minutes to spare.

`Python` `NLP` `AI APIs`

---

### [JPMC Midas Core](https://github.com/winnerumukoro/forage-midas)
Enterprise software engineering simulation from J.P. Morgan Chase (Forage). Built on the Midas financial platform using Java and Spring Boot - gave me a real taste of structured, production-style engineering workflows.

`Java` `Spring Boot` `Maven`
